Entry for the make.fun bounty [Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605): one haiku about debugging, three lines in the 5-7-5 syllable shape.

```text
breakpoint holds its breath
one wrong line, the whole night bends
semicolon, gone
```

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` (Python 3.13, standard library only) writes the haiku to `/output/entry.txt` — exactly 81 bytes, no trailing newline, byte-identical on every run.
